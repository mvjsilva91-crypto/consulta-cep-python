# 📍 Consulta de CEP com Python

Aplicação em Python que consulta informações de endereço a partir de um CEP utilizando a API ViaCEP.

## 🚀 Funcionalidades
- Consulta de CEP
- Validação de entrada
- Tratamento de erros
- Exibição de endereço completo

## 🌐 API utilizada
- ViaCEP

## 🛠️ Tecnologias
- Python
- Requests
- pandas

## ▶️ Como executar

```bash
pip install -r requirements.txt
python main.py
